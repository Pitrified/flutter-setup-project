# Phase 1 decision - vendored scanner vs `llm_json_stream`

Decision record for [`01_feat_partial_json_parser.md`](01_feat_partial_json_parser.md)
("Decision to make first" section). Outcome: **vendored**.

## What phase 1 actually requires

The fixed public surface (plan Goals 1-4):

- A synchronous pure function `PartialJsonResult parse(String cumulativeBuffer)`.
- Input is the *whole buffer so far*, not a delta. Re-parse each tick.
- Output is the *whole* best-effort `Map<String,dynamic>` plus **per-node
  closed-flags**: which container/leaf was closed by a real `]` / `}` / `"` in
  the input vs. synthesized at EOF. This is the signal phase 6 uses for "this
  row is final" and "no more rows coming."
- Schema-agnostic (no `TutorResponse` knowledge), no Flutter imports.

## `llm_json_stream` - facts

Source: [pub.dev/packages/llm_json_stream](https://pub.dev/packages/llm_json_stream)
(fetched 2026-06-22).

- v1.0.0, published ~32 days ago (0.4.x before). Single verified publisher.
  MIT, null-safe, pure Dart; only depends on `meta`. ~10 likes, ~13k downloads,
  160 pub points, 504 passing tests.
- Input model: **stateful**, fed a `Stream<String>` of *incremental deltas*,
  parsed character-by-character across chunks.
- Output model: **reactive path-subscriptions** - `.str('user.name')`,
  `.list('items')`, `.stream`, `.future`, plus `onElement` / `onProperty`
  callbacks that fire when a node *starts*.
- Strengths: handles escapes, unicode, scientific notation, and chunk-boundary
  splitting - exactly the tokenizer edge cases the vendored path would own.

## Mismatch against our required surface

1. **Input shape is inverted.** It wants deltas and holds internal state; our
   contract is "re-parse the whole cumulative buffer each tick, pure function."
   Usable only by wrapping a stateful object and feeding it synthesized deltas -
   working against its grain.
2. **No whole-map snapshot without known paths.** It emits per-subscribed-path.
   We are schema-agnostic and do not know the paths (the entire point of staying
   generic over `TutorResponse`). Reconstructing the full nested partial map each
   tick is not what the API is built for.
3. **Closed-flags - the decisive gap.** Its callbacks fire when a node *starts*;
   the only completion signal is a single root `.future`. There is **no per-node
   closed event**. Our phase-6 signal is precisely per-array and per-element
   *closed*, so we would hand-write that tracking on top of the dep anyway - the
   part we would most want to inherit.

## Comparison

| Dimension                              | Vendored scanner (~120-150 lines) | `llm_json_stream`                     |
| -------------------------------------- | --------------------------------- | ------------------------------------- |
| Hard tokenizing (escapes/unicode/nums) | we own it                         | solved, well-tested                   |
| Whole-map-per-tick snapshot            | native output                     | not native; reconstruct               |
| Per-node closed-flags                  | native (we track the stack)       | absent - hand-write anyway            |
| Sync pure `parse(buffer)` API          | exact fit                         | wrap stateful stream                  |
| Dep / maintenance cost                 | zero                              | young pkg, 1 maintainer, on hot path  |
| Project rule (`no new deps` w/o OK)    | clean                             | needs explicit approval               |

## Verdict

**Vendored.** The dep would save the tokenizer edge cases, but it does not
provide the two things this phase's API is shaped around (whole-map snapshot +
per-node closed-flags) - we would build those on top regardless, while
inheriting a stateful reactive model we must adapt and a young single-maintainer
dependency on the per-token hot path. The vendored scanner's main cost (owning
escape / unicode / number edge cases) is bounded and is exactly what the plan's
test list already enumerates. Keep the public API identical to what the plan
specifies so the choice does not leak past this phase; revisit only if the
edge-case surface proves larger than the fixture list.
