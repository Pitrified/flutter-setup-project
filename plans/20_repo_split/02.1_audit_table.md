# Audit table

Side-document of [`02_audit.md`](02_audit.md). Written 2026-09-26 against `main` at `ef6eef4` plus this branch's plan commits.
Every tracked path matches at least one pattern in the `Paths` column; the check is in the phase log.

Destinations:

- `fala`: moves to fala-language-tutor only.
- `guide`: stays here only.
- `both`: in both repos. "rewritten" means each repo gets its own version rather than a copy.
- `link`: lives in fala-language-tutor; the guide links to it.
- `drop`: nobody keeps it.

Every row is a proposal. Where the reason is "unused", it was checked with `grep` over `lib/`, `test/` and `integration_test/` on 2026-09-26.
