The two issues you're hitting are related — the `tools.zip` download failed (the file is corrupted/incomplete), and Android Studio installed without the cmdline-tools component. Here's how to fix both paths:

## The actual problems

1. **Corrupted download** — `tools.zip` didn't download correctly. The `curl` command in the doc uses `-o` which doesn't follow redirects by default on some versions, or the URL may have changed.

2. **Android Studio missing cmdline-tools** — When you extracted Android Studio manually (instead of running the setup wizard), the SDK wizard never ran, so no SDK components were installed at all.

---

## Fix: Option B (cmdline-tools only) — the cleaner path

```bash
# Remove the bad download
rm ~/android-sdk/cmdline-tools/tools.zip

# Re-download with -L to follow redirects
cd ~/android-sdk/cmdline-tools
curl -L -o tools.zip "https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip"

# Verify it's a real zip before extracting
file tools.zip   # should say "Zip archive data"

# Extract
unzip tools.zip

# The zip extracts to a folder named "cmdline-tools", rename it to "latest"
mv cmdline-tools latest

# Your structure should now be:
# ~/android-sdk/cmdline-tools/latest/bin/sdkmanager
ls ~/android-sdk/cmdline-tools/latest/bin/
```

Then make sure your PATH is actually set in your current shell:

```bash
export ANDROID_HOME="$HOME/android-sdk"
export PATH="$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH"

# Verify sdkmanager is found
which sdkmanager
sdkmanager --version
```

Then proceed normally:

```bash
sdkmanager "platform-tools" "build-tools;34.0.0" "platforms;android-34"
flutter doctor --android-licenses
```

---

## Fix: Option A (Android Studio) — if you prefer the GUI

The Studio zip you extracted just contains the IDE — you still need to run its setup wizard to get the SDK:

```bash
# Run the studio installer (adjust path to where you extracted it)
~/android-studio/bin/studio.sh
```

Walk through the setup wizard. On the **SDK Components Setup** screen, make sure **Android SDK Command-line Tools** is checked. That's the component that provides `sdkmanager`.

If you already dismissed the wizard, go to **SDK Manager → SDK Tools tab** and install **Android SDK Command-line Tools (latest)** from there.

---

## Doc fix

The `curl` line in the doc should use `-L` and ideally a versioned filename to avoid ambiguity:

```bash
# Before (fragile)
curl -o tools.zip https://dl.google.com/android/repository/commandlinetools-linux-latest.zip

# After (robust)
curl -L -o tools.zip "https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip"
```

The `-L` flag tells curl to follow HTTP redirects, which Google's download URLs require.
